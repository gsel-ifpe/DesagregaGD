# Projeto DesagregaGD

Este repositório contém os arquivos para o sistema de estimativa de carga em alimentadores de distribuição, desenvolvido para [Nome da Disciplina ou Finalidade].

## Arquivos do Projeto

Aqui está uma descrição do que cada arquivo faz:

* **`paginaweb.html`**: A página principal da aplicação web.
* **`sobre.html`**: A página que descreve o projeto ou a equipe.
* **`exemplos.html`**: Página que demonstra os exemplos de uso.
* **`Exemplo *.csv`**: Arquivos com dados de exemplo de carga e irradiação fotovoltaica.
* **`GSEL 1x1 (1).svg`**: Logo ou imagem utilizada no projeto.

## Como Executar

Para visualizar as páginas, basta abrir os arquivos `.html` em um navegador web.
